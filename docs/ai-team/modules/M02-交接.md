## 4. 关键决策（下个会话不要重做）
- 分层：core（types/events/exceptions）→ tools（@tool 推导 JSON Schema + Registry 错误折算）→ providers（Provider 协议/OpenAICompat/Fake）→ agent.py 循环 + memory（协议 + InMemoryMemory）。
- 对外 API（已定，M3 文档以此为准）：`Agent(provider, tools, system_prompt, memory, max_iterations, on_event).run(user_input) -> AgentResult`；`@tool` 装饰器从签名/docstring 推 schema；`OpenAICompatProvider(base_url 默认 DeepSeek, api_key env 链)`；错误一律折算 ProviderError/ToolResult(is_error) 不外抛。
- 已接纳为正式语义的三处（审查员记档）：max_iterations<1 构造期报错；未配置工具收到 tool_calls 时折算错误结果回喂；达上限在第 N+1 次请求前抛 MaxIterationsError。
- 测试策略：全离线（FakeProvider + httpx.MockTransport），真实 API 调用不进测试。
- 被否：并行 worktree（工作区=仓库根，违反门禁零 ignored 文件）→ 串行单写者。
